# Код проверки NTC

`ntc_test/ntc_test.ino` — минимальный скетч Arduino для ESP32-C6:
пять NTC на GPIO2, GPIO3, GPIO4, GPIO5 и GPIO6, усреднение 16 измерений,
вывод напряжений в милливольтах примерно раз в секунду.
Сторонние библиотеки датчиков не нужны; используется Arduino core для ESP32.

Каждый датчик подключён отдельным делителем:

```text
3.3V ── NTC ──┬── постоянный резистор ── GND
              └── GPIO (2–6)
```

При нагревании NTC напряжение увеличивается.

Открой `ntc_test/ntc_test.ino` в Arduino IDE, выбери свою плату ESP32-C6
и порт, загрузи скетч. Скорость Serial Monitor — 115200 бод.

Температура пока не рассчитывается: нужны сопротивления постоянных
резисторов, номиналы NTC при 25 °C и коэффициенты B.
