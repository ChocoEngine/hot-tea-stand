# Прижим эпоксидного NTC к шайбе

Файл `ntc_washer_clamp_example.3dm` показывает один печатный прижим в сборе.
Он рассчитан на примерную эпоксидную каплю Ø4 × 3,5 мм и широкую шайбу M4
Ø12 × 1 мм с отверстием Ø4,3 мм.

Прижим состоит из двух крепёжных площадок, гибкой перемычки толщиной 1 мм и
центральной нажимной площадки Ø5 мм. Два винта M2 притягивают его к стойкам Ø5
мм, объединённым с внутренней поверхностью верхней панели. В стойках показаны
пилотные отверстия Ø1,6 мм для прямого вкручивания M2 в пластик.

## Сборка

1. Обезжирить нижнюю поверхность шайбы.
2. Нанести на NTC минимальный слой ARCTIC MX-4.
3. Поместить каплю непосредственно под плоскую часть шайбы.
4. Установить прижим нажимной площадкой к нижней стороне капли.
5. Равномерно затянуть два M2 без заметного изгиба шайбы.
6. Зафиксировать выводы нейтральным силиконом вне теплового контакта.

Красные цилиндры слоя `04` нужно вычесть через `MeshBooleanDifference`.
Зелёные элементы слоя `01` после вычитания объединяются командой
`MeshBooleanUnion` и печатаются одной маленькой деталью. Для пяти датчиков
прижим копируется пять раз.

Перед переносом в корпус размеры следует исправить под фактическую каплю NTC.
Для гибкой перемычки предпочтителен PETG; PLA может растрескаться при затяжке.
